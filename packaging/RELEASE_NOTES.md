AI Builder 0.1.0 preview for Windows x64.

Includes a desktop app launcher, per-user installer/uninstaller, bundled Node.js runtime, Pi 1.4.0 and llama.cpp b11960 CPU runtime. Supports local projects, saved chats, optional ChatGPT subscription connection and a bounded planner/local-worker Auto mode.

Model weights are not included. Existing users retain their local model. New users must provide a Qwen3.5 4B GGUF. Git for Windows is required for command execution. GitHub CLI is an optional separately installed integration.

Unsigned preview, not a stable release. No clean-machine verification yet. Dedicated GitHub UI, Copilot connection, speech and computer control are not included. The agent executes with the user's privileges; project folders are not a security sandbox. Cloud use remains subject to provider limits.

No credentials, saved conversations, personal project files or model weights are included in the installer. Uninstall retains user-created state and projects.
